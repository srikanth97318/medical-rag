# 🩺 Medical RAG: Minimizing Hallucinations and Off-Topic Responses in Medical Question Answering

A Retrieval-Augmented Generation (RAG) based Medical Question Answering system designed to reduce hallucinated and off-topic responses generated by Large Language Models (LLMs). The system combines semantic retrieval, multi-stage verification, and self-correction to improve the factual accuracy and reliability of AI-generated medical answers.

# 🚀 Introduction

Large Language Models have significantly improved Medical Question Answering by generating natural and context-aware responses. However, these models often produce hallucinated or irrelevant information, making them unreliable for healthcare applications.

This project addresses the issue using Retrieval-Augmented Generation (RAG), where responses are grounded using trusted medical documents before generation. A multi-stage evaluation framework verifies every response before it is returned to the user.

---

# 🎯 Problem Statement

Medical Question Answering systems powered by Large Language Models frequently generate:

- Hallucinated information
- Unsupported medical facts
- Off-topic responses
- Low-confidence answers

The objective of this project is to build a reliable Medical RAG system capable of detecting, verifying, and correcting these responses before presenting them to users.

---

# 🎯 Objectives

- Build a Medical Question Answering system using RAG

# 🔄 Workflow

1. User submits a medical question.
2. Question embedding is generated.
3. Relevant medical documents are retrieved from FAISS.
4. Retrieved documents are passed to Qwen2.5-3B-Instruct.
5. The LLM generates an answer.
6. The answer is evaluated using:
   - SelfCheckGPT
   - Natural Language Inference
   - Faithfulness
   - G-Eval
   - Prometheus
7. If hallucinations are detected, the answer is regenerated.
8. The verified response is returned to the user.
